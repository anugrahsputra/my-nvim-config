# Minuet AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Supermaven inline completion with Minuet virtual text using Claude.

**Architecture:** A dedicated Lazy plugin spec initializes Minuet with its Claude provider and virtual-text frontend. `nvim-cmp` stays independent, so it continues to show only LSP, snippet, buffer, and path completions.

**Tech Stack:** Neovim 0.12, Lua, lazy.nvim, minuet-ai.nvim, Anthropic API.

---

### Task 1: Replace the inline completion plugin

**Files:**
- Create: `lua/conput/plugins/minuet.lua`
- Delete: `lua/conput/plugins/supermaven.lua`
- Modify: `docs/superpowers/specs/2026-07-19-minuet-ai-design.md`

- [ ] **Step 1: Correct the documented line-accept behavior**

Replace the `<C-j>` description in the spec with `accepts the current line of the suggestion`, matching Minuet's `accept_line` action.

- [ ] **Step 2: Add the Lazy specification**

Create `lua/conput/plugins/minuet.lua` with:

```lua
return {
    "milanglacier/minuet-ai.nvim",
    config = function()
        require("minuet").setup({
            provider = "claude",
            virtualtext = {
                auto_trigger_ft = { "*" },
                keymap = {
                    accept = "<C-y>",
                    accept_line = "<C-j>",
                    dismiss = "<C-]>",
                },
            },
        })
    end,
}
```

Minuet uses its supported Claude defaults, including `claude-haiku-4.5` and the `ANTHROPIC_API_KEY` environment-variable name. No credential belongs in the file.

- [ ] **Step 3: Remove the superseded plugin spec**

Delete `lua/conput/plugins/supermaven.lua` so Lazy no longer loads Supermaven or its mappings.

- [ ] **Step 4: Validate the Lua configuration**

Run: `nvim --headless "+Lazy! sync" "+qa"`

Expected: Lazy installs Minuet and exits without Lua errors.

- [ ] **Step 5: Verify the resolved plugin state**

Run: `rg -n 'minuet-ai.nvim|supermaven-inc/supermaven-nvim' lazy-lock.json lua/conput/plugins`

Expected: Minuet appears in the lockfile and plugin specs; Supermaven appears in neither.

- [ ] **Step 6: Commit**

```bash
git add lua/conput/plugins/minuet.lua lua/conput/plugins/supermaven.lua lazy-lock.json docs/superpowers/specs/2026-07-19-minuet-ai-design.md docs/superpowers/plans/2026-07-19-minuet-ai.md
git commit -m "feat(nvim): replace Supermaven with Minuet"
```
